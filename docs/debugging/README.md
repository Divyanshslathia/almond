# Debugging Log

This directory contains records of non-trivial bugs encountered during development.

## Structure

Each debugging entry follows this format:

```text
Problem
   ↓
Observed behavior
   ↓
Initial hypothesis
   ↓
Investigation
   ↓
Root cause
   ↓
Fix
   ↓
What was learned
```

## Entries

Debugging entries will be added as non-trivial bugs are encountered and resolved.

## Purpose

Debugging is a core part of learning how systems work. By documenting the debugging process, we create a resource that:

1. Shows how to investigate problems systematically
2. Reveals common pitfalls in network programming, parsing, etc.
3. Deepens understanding of underlying concepts
4. Helps others who encounter similar issues

## Purpose

The learning log serves multiple purposes:

1. Records discoveries and insights
2. Documents bugs and how they were fixed
3. Tracks misconceptions that were corrected
4. Notes experiments that were useful
5. Identifies limitations of current implementation
6. Previews what the next feature will teach

This makes the repository useful as a study resource for understanding how browsers work from the ground up.

# Concepts

This directory contains detailed explanations of fundamental concepts encountered while building the browser.

## Concept Documents

As concepts are introduced, they will be documented here:

- **URLs** - Understanding web addresses
- **DNS** - Domain name resolution
- **IP** - Internet Protocol addressing
- **TCP** - Transmission Control Protocol
- **Sockets** - Network programming interface
- **HTTP** - Hypertext Transfer Protocol
- **Bytes and Encoding** - Data representation
- **HTML Parsing** - Document structure
- **DOM** - Document Object Model
- **CSS** - Styling and layout
- **Rendering** - Drawing to screen

Each concept document will answer:

1. What is it?
2. Why does it exist?
3. What problem does it solve?
4. How does it work?
5. Where does it sit in the browser?
6. What does the OS do?
7. How does our Python implementation relate to it?
8. What are common misconceptions?
9. What should we investigate next?

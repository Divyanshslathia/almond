# Browser Documentation

This documentation explains how this browser works from the ground up.

## Purpose

This is a learning browser built to understand:

- Operating systems
- Networking protocols (DNS, TCP, HTTP)
- Web technologies (HTML, CSS, JavaScript)
- Browser architecture
- System-level programming

The browser is intentionally built **from scratch** to expose the concepts that production browsers abstract away.
